## 2. 安命身十二宮

### 2.1 口訣

> 寅起正月，順數至生月，**逆數生時**為命宮。
> 寅起正月，順數至生月，**順數生時**為身宮。

### 2.2 算法

以寅宮為起點（索引 0），順時針排列十二宮。

```javascript
// 關鍵：所有計算以寅宮為 0
// monthIndex = 農曆月份 - 1（0-indexed，正月=0）
// timeIndex = 時辰索引（0=子, 1=丑, ..., 11=亥）

// 命宮索引（以寅宮為 0）
soulIndex = (monthIndex - timeIndex + 12) % 12;

// 身宮索引（以寅宮為 0）
bodyIndex = (monthIndex + timeIndex) % 12;
```

### 2.3 宮位排列

命宮確定後，逆時針佈十二宮：

```
命宮 → 父母宮 → 福德宮 → 田宅宮 → 官祿宮 → 交友宮
→ 遷移宮 → 疾厄宮 → 財帛宮 → 子女宮 → 夫妻宮 → 兄弟宮
```

```javascript
const PALACES = ['命宮','父母','福德','田宅','官祿','交友','遷移','疾厄','財帛','子女','夫妻','兄弟'];

function getPalaceNames(soulIndex) {
  const names = [];
  for (let i = 0; i < 12; i++) {
    names[i] = PALACES[(12 - soulIndex + i) % 12];
  }
  return names;
}
```

### 2.4 範例

**1988年 農曆7月 辰時生：**
- monthIndex = 7 - 1 = 6
- timeIndex = 4（辰時）
- soulIndex = (6 - 4 + 12) % 12 = 2
- bodyIndex = (6 + 4) % 12 = 10

命宮在寅宮起第 2 格 = **辰宮**

## 4. 起紫微星

### 4.1 口訣

> 六五四三二，酉午亥辰丑，
> 局數除日數，商數宮前走；
> 若見數無餘，便要起虎口，
> 日數小於局，還直宮中守。

### 4.2 算法（iztro 實作）

```javascript
function getZiweiIndex(lunarDay, fiveElementsValue) {
  let offset = -1;
  let quotient, remainder;

  do {
    offset++;
    const divisor = lunarDay + offset;
    quotient = Math.floor(divisor / fiveElementsValue);
    remainder = divisor % fiveElementsValue;
  } while (remainder !== 0);

  quotient %= 12;
  let ziweiIndex = quotient - 1;

  if (offset % 2 === 0) {
    ziweiIndex += offset;  // 偶數：順行
  } else {
    ziweiIndex -= offset;  // 奇數：逆行
  }

  ziweiIndex = (ziweiIndex % 12 + 12) % 12;

  // 天府位置 = 12 - 紫微位置
  const tianfuIndex = (12 - ziweiIndex) % 12;

  return { ziweiIndex, tianfuIndex };
}
```

### 4.3 步驟解析

1. 用五行局數除農曆生日
2. 找到能整除的最小倍數（生日 + 偏移量）
3. 計算商數和偏移量
4. 從寅宮起，按商數定位
5. 若偏移量為奇數，逆行偏移量步；偶數則順行
6. 落宮即為紫微星位置

### 4.4 範例

**農曆10日，土五局（5）：**
- 10 ÷ 5 = 2，餘數 0，offset = 0
- quotient = 2, ziweiIndex = 2 - 1 + 0 = 1
- 紫微在 **丑宮**（寅宮起第 1 格）

**農曆13日，火六局（6）：**
- 13 + 5 = 18, 18 ÷ 6 = 3, 餘 0, offset = 5
- quotient = 3, ziweiIndex = 3 - 1 = 2
- offset = 5（奇數），ziweiIndex = 2 - 5 = -3
- ziweiIndex = (-3 + 12) % 12 = 9
- 紫微在 **酉宮**

## 5. 安主星

### 5.1 紫微星系（逆時針）

口訣：
> 紫微逆去天機星，隔一太陽武曲辰，
> 連接天同空二宮，廉貞居處方是真。

```javascript
const ziweiGroup = [
  '紫微',    // 紫微位置
  '天機',    // 紫微 - 1
  '',        // 空
  '太陽',    // 紫微 - 3
  '武曲',    // 紫微 - 4
  '天同',    // 紫微 - 5
  '',        // 空
  '',        // 空
  '廉貞'     // 紫微 - 8
];

// 安星：從紫微位置逆時針排列
ziweiGroup.forEach((star, i) => {
  if (star !== '') {
    const pos = (ziweiIndex - i + 12) % 12;
    // 安星於 pos 宮
  }
});
```

## 6. 安輔星

### 6.1 左輔右弼（按生月）

口訣：
> 辰上順正尋左輔，戌上逆正右弼當。

```javascript
function getZuoYouIndex(lunarMonth) {
  const zuoIndex = (2 + (lunarMonth - 1) + 12) % 12;  // 辰=2，順數
  const youIndex = (10 - (lunarMonth - 1) + 12) % 12;  // 戌=10，逆數
  return { zuoIndex, youIndex };
}
```

### 6.2 文昌文曲（按時辰）

口訣：
> 辰上順時文曲位，戌上逆時覓文昌。

```javascript
function getChangQuIndex(timeIndex) {
  const changIndex = (10 - timeIndex + 12) % 12;  // 戌=10，逆數
  const quIndex = (2 + timeIndex + 12) % 12;       // 辰=2，順數
  return { changIndex, quIndex };
}
```

### 6.3 天魁天鉞（按年干）

// 甲戊庚之年丑未

function getKuiYueIndex(heavenlyStem) {

### 6.4 祿存、擎羊、陀羅（按年干）

> 庚祿定居申，辛祿酉上補。壬祿亥中藏，癸祿居子戶。

function getLuYangTuoIndex(heavenlyStem) {
  const luTable = { '甲':2, '乙':3, '丙':5, '丁':6, '戊':5, '己':6, '庚':8, '辛':9, '壬':11, '癸':0 };

## 8. 完整範例驗證

### 案例：1988年 農曆7月10日 辰時 男命

**Step 1：安命宮**
- monthIndex = 7 - 1 = 6
- timeIndex = 4（辰時）
- soulIndex = (6 - 4 + 12) % 12 = 2
- 命宮在寅宮起第 2 格 = **辰宮**

**Step 2：定五行局**
- 年干 = 戊 → 天干取數 3
- 命宮地支 = 辰 → 地支取數 3
- 3 + 3 = 6 → 6 - 5 = 1 → 木三局 → **局數 = 3**

**Step 3：起紫微**
- 農曆 10 日，木三局（3）
- 10 + 2 = 12, 12 ÷ 3 = 4, 餘 0, offset = 2
- quotient = 4, ziweiIndex = 4 - 1 = 3
- offset = 2（偶數），ziweiIndex = 3 + 2 = 5
- 紫微在 **巳宮**
- 天府 = 12 - 5 = 7，天府在 **未宮**

**Step 4：安紫微星系**
- 紫微(5) → 巳
- 天機(5-1=4) → 辰
- 太陽(5-3=2) → 寅
- 武曲(5-4=1) → 丑
- 天同(5-5=0) → 子
- 廉貞(5-8=-3→9) → 酉

**Step 5：安天府星系**
- 天府(7) → 未
- 太陰(8) → 申
- 貪狼(9) → 酉
- 巨門(10) → 戌
- 天相(11) → 亥
- 天梁(0) → 子
- 七殺(1) → 丑
- 破軍(7+10=17→5) → 巳
